# 什么是 R2

R2 是 Cloudflare 的对象存储服务，兼容 S3 API，没有出口流量费用，很适合个人站点存放图片和文件。

## 文件列表

开发模式里，云盘接口可以通过 S3 API 的 `ListObjectsV2` 读取桶内对象。把 `delimiter` 设置为 `/`，就能得到类似文件夹的层级结构。

## 下载链接

公开桶可以直接拼出对象链接；私有桶则使用预签名 URL。两种方式都只需要在云盘数据里保存一个可访问的地址。

## 构建时的处理

生产构建时，云盘使用预生成的清单文件，不依赖运行时接口。这样静态站点在任何环境都能稳定展示目录结构。
